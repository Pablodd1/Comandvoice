02 • The Symbiotic Architecture Auto-Discovery + Deep Host Handshake

Symbiotic Website Absorption:
Zero-Config on Day 1, Deep Integration on Demand.

VoiceLayer operates in two simultaneous layers: it immediately scans any standard webpage with zero developer setup, and automatically upgrades into a deep personalized concierge when the host exposes a Symbiosis manifest.

Level 1 — Automatic DOM & Schema Absorption

Works Out-of-the-Box on Any Public Webpage

On page load, VoiceLayer’s Scanner indexes headings, SPA navigation buttons, product cards, prices, stock badges, and Schema.org JSON-LD in under 15 milliseconds—and re-scans automatically via MutationObserver when tabs change.

Level 2 — Universal Symbiosis Protocol

Repo-to-Repo & AI-Developer Handshake

Any host app or AI coding agent can call VoiceLayer.symbiosis.handshake({...}) or set window.__VOICELAYER_SYMBIOSIS__ to feed live user profiles, dual calendars, pending regimens, and custom JavaScript actions in one declarative object.

03 • Spatial Intelligence & Trust Deictic Resolution + Read-Back Verification

It Knows What You’re Looking At—
And Proves Every Action It Takes.

Unlike LLM wrappers that guess or hallucinate, VoiceLayer combines live viewport geometry with a strict verification pipeline before and after every click.

01

Deictic “This / These” Resolution

Tracks scroll depth, viewport center, and pointer hover. When a user says “How much is this?” or “Add 2 of these to my cart”, VoiceLayer resolves the exact product card in focus.

Focus: Pulse Earbuds ($79)
02

Highlight → Pause → Real Click → Verify

Every action shows a visual highlight ring, pauses briefly so any mouse or key touch can cancel it, dispatches real pointer/mouse events, and re-reads the live DOM cart count to issue a verified: true receipt.

Receipt: status: "succeeded"
Verify: read_back (cart 3 → 4)
03

Polite Modal & Auth-Gate Yielding

When a host site displays a login screen, password form, or privacy consent dialog ([role="dialog"]), VoiceLayer automatically yields out of the way and restores itself the moment the modal closes.

04 • Personal Concierge Engine Multi-User & Bilingual EN / ES

Executive Daily Briefing, Multi-User Isolation,
and Instant Bilingual Parity.

For portals, membership sites, wellness platforms, and enterprise dashboards, VoiceLayer synthesizes everything pending for the active user into a warm, human briefing.

1. Unified 5-Part Executive Briefing

“What is pending today?”

Combines Live Weather (temperature + sky state vs. rain probability), Primary Calendar (appointments), Second Calendar (work meetings, training, flights/trips), Pending to Take/Do, and Pending to Buy/Refill (low supply + multi-quantity N× cart items).

2. Strict Multi-User Memory Isolation

VoiceLayer.setUser(id, profile)

When switching accounts or personas on shared devices, VoiceLayer partitions profile storage, session behavior, calendars, regimens, and refills per user ID—with zero cross-user data leakage.

3. Automatic Per-Utterance Bilingual Switching

English & Español

Visitors don’t even need to click a language toggle: asking “¿Qué tengo pendiente hoy?” or “¿Cómo dormí anoche?” in default mode automatically responds in natural Spanish.
