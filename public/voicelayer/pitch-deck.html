02 • The Symbiotic Architecture Auto-Discovery + Deep Host Handshake

Symbiotic Website Absorption:
Zero-Config on Day 1, Deep Integration on Demand.

VoiceLayer operates in two simultaneous layers: it immediately scans any standard webpage with zero developer setup, and automatically upgrades into a deep personalized concierge when the host exposes a Symbiosis manifest.

Level 1 — Automatic DOM & Schema Absorption

Works Out-of-the-Box on Any Public Webpage

On page load, VoiceLayer’s Scanner indexes headings, SPA navigation buttons, product cards, prices, stock badges, and Schema.org JSON-LD in under 15 milliseconds—and re-scans automatically via MutationObserver when tabs change.

Level 2 — Universal Symbiosis Protocol

Repo-to-Repo & AI-Developer Handshake

Any host app or AI coding agent can call VoiceLayer.symbiosis.handshake({...}) or set window.__VOICELAYER_SYMBIOSIS__ to feed live user profiles, dual calendars, pending regimens, and custom JavaScript actions in one declarative object.

03 • Hands-Free Voice Commands Real DOM Clicks Closed-Loop Verification

It Doesn't Just Talk—
It Listens, Clicks, and Operates the Page.

Unlike passive chatbots that only generate text, VoiceLayer accepts direct voice commands, targets the exact button or form field on the screen, dispatches real clicks, and verifies the result with audible confirmation.

1. Natural Voice Commands

Spoken Intent

Visitors speak naturally: “Add 2 of these to my cart”, “Show me supplements under $50”, or “Open my appointments”. VoiceLayer parses intent in <10ms without slow round-trips.

2. Spatial Focus & Highlight Ring

Visible Confirmation

Scores visible buttons across 9 DOM signals (viewport center, hover, text relevance) and illuminates the target with a visible green confirmation ring so the user sees exactly what will be clicked.

3. Real DOM Click & Read-Back Receipt

Verified Outcome

Dispatches native mouse/pointer events, re-reads the page state (e.g. cart badge count, opened modal), and provides spoken feedback: “Done — I added 2 to your cart, total is now 3.”

05 • Symbiotic Host Communication Two-Way Event Bridge Unmet Demand Intelligence

Lives Symbiotically on the Page—
And Reports User Demand Back to the Site Owner.

VoiceLayer does not live in an isolated black box. It maintains an active two-way bridge with the host webpage, reporting real-time customer demand, unfulfilled searches, and verified conversions directly back to the site owner.

1. Two-Way Host Event Bus

Live DOM Events

Dispatches native JavaScript custom events (vl:action-verified, vl:demand-captured, vl:user-switched) to the host window so the page can react dynamically to spoken commands.

2. Reports Unmet Customer Demand

Missing Inventory Alert

When a visitor asks for a product, service, or date slot not currently on the page, VoiceLayer logs the exact intent—showing business owners what customers are trying to buy so they can stock it.

3. Automated Conversion Receipts

Voice ROI Tracking

Every voice-driven checkout, cart addition, and form submission emits an audit receipt to the site’s analytics (GA4, Mixpanel, custom webhooks) with zero manual tagging.

06 • Privacy & Cloud Architecture 100% Private by Design Zero Local Machine Dependency

100% Private by Design:
Client-Side Security & Cloud Freedom.

Total user privacy and data sovereignty. VoiceLayer runs entirely inside the user's browser, keeping personal schedules, biometrics, and voice interactions strictly confidential—with zero dependencies on your local machine.

1. Client-Side Edge Execution

Zero Audio Saved

Speech recognition and intent parsing execute in the browser. Voice audio is never recorded, transmitted to third-party ad networks, or stored on remote cloud servers.

2. Isolated Local Storage Vault

vl_memory_site_user

Personal schedules, wellness biometrics, and daily tasks live in encrypted local browser storage. Personal data stays on the user's device—never harvested or sold.

3. Hard-Coded Safety Guardrails

Strict Field Shielding

Automatically ignores passwords, credit cards, CVVs, and sensitive authentication fields. Destructive actions (checkout, delete) require explicit audible confirmation.
